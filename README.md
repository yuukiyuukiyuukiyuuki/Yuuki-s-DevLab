# Yuuki's DevLab | 個人開発の洗練Webツール集ポータル

日常や開発作業をスマートに、快適にするための個人開発Webツールラボです。  
すべてのツールは**完全クライアントサイド（ブラウザ内）**で高速かつ安全に動作します。

## 🌟 サイトの理念とセキュリティ（プライバシー保護）

当サイトで提供しているWebアプリケーションは、すべて**ユーザーのプライバシーとデータセキュリティを最優先**に設計されています。

- **100% ブラウザ内完結処理**  
  入力したテキストやアップロードした画像データが外部サーバーへ送信・保存されることは一切ありません。
- **安心のプライバシー保護**  
  機密データや個人写真、業務メモなども安心してお使いいただけます。
- **高速＆登録不要**  
  アカウント登録やログインの手間なく、ブラウザを開いてすぐに全機能をご利用いただけます。

## 🛠️ 公開中ツール一覧

### 1. [TextMetrics PRO] リアルタイム文字数カウント＆高度文章分析
文章執筆、レポート作成、SNS投稿、Webライティングに特化した高機能テキストアナライザー。
- **主要機能**:
  - 総文字数（スペース含む/除く）のリアルタイム高精度カウント（絵文字・サロゲートペア対応）
  - 原稿用紙換算（400字詰めの枚数・余り文字数・小数点表記）
  - 読了時間の目安（黙読: 約600字/分、音読: 約350字/分）
  - 文字種別内訳分析（ひらがな/カタカナ/漢字/英数字/記号をカラーバー表示）
  - スマート整形（連続空白の統合、不要な改行・行末スペースのワンクリック整理）
  - 目標文字数プログレスバー ＆ ブラウザ内自動保存（localStorage）

### 2. [ImageCraft PRO] 高速画像リサイズ＆WebP一括変換ツール
ドラッグ＆ドロップで手軽に画像を軽量化・最適化できるクライアントサイド画像ユーティリティ。
- **主要機能**:
  - 次世代フォーマット WebP への一括変換（JPEG/PNG 相互変換対応）
  - リアルタイム画質・圧縮率スライダー（削減率の即座シミュレーション）
  - 比率縮小（75%, 50%, 25%）および最大幅（px）指定リサイズ（アスペクト比完全維持）
  - EXIFメタデータ（撮影日時・GPS位置情報・カメラ情報）の自動削除によるプライバシー保護
  - 変換後画像の一括ZIPダウンロード ＆ 個別保存
