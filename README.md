# Yuuki's DevLab - 個人開発便利ツール集ポータル

個人で開発した便利なWebツールをひとまとめにして管理・公開できる、モダンなポータルサイトです。

---

## 🌟 サイトの構成と特徴

1. **統一された世界観・デザイン**
   - 深みのあるダークテーマ ＆ クリーンなライトテーマ（ワンクリック切り替え）
   - アンビエントグロー背景 ＆ グラスモーフィズム（すりガラス効果）
   - 洗練されたタイポグラフィとカードスタイル
   - モバイル・タブレット・PC完全対応のレスポンシブデザイン

2. **充実の機能**
   - **リアルタイム検索**：ツール名・キーワード・説明文からインクリメンタル検索（`Ctrl + K` で即座に検索窓にフォーカス）
   - **カテゴリ別タブ切り替え**：すべて / テキスト / 画像・メディア / 開発・ユーティリティ
   - **ステータスバッジ**：公開中（Live）、開発中、構想中
   - **プライバシーポリシー＆お問い合わせモーダル**

3. **推奨フォルダ構成**
   ポータルから各ツールへ快適にアクセスするための推奨フォルダ構成です。
   ```text
   自作ツール/
   ├── index.html        (ポータルトップページ)
   ├── style.css         (ポータル用スタイル)
   ├── script.js         (ポータル用スクリプト)
   ├── README.md
   └── tools/
       ├── text-metrics/ (TextMetrics PRO のファイル群)
       │   ├── index.html
       │   ├── style.css
       │   ├── script.js
       │   └── README.md
       └── image-tools/  (今後作成するツール)
   ```

---

## 🚀 使い方
1. `自作ツール` フォルダ内の [index.html](file:///c:/Users/Yuuki/OneDrive/Desktop/自作ツール/index.html) をダブルクリックしてブラウザで開きます。
2. ポータル画面から各ツールのカードをクリックして、各Webアプリを起動できます。
