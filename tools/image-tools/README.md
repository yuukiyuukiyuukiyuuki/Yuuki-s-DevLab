# ImageCraft PRO - ブラウザ完結の高速画像リサイズ＆WebP一括変換ツール

サーバー送信なしで100%ブラウザ内（HTML5 Canvas API）で完結する、高速・安全な画像リサイズ＆フォーマット一括変換Webアプリケーションです。

---

## 🌟 主な機能と特徴

### 1. ブラウザ内完全完結（プライバシー保護＆超高速）
- 画像データは外部サーバーに一切送信されず、すべてお使いの端末（ブラウザ）のメモリ上で瞬時に処理されます。
- 個人写真、機密情報を含むスクリーンショット、業務資料なども安心・安全に軽量化可能です。

### 2. 充実の画像変換＆編集機能
- **フォーマット相互一括変換**：
  - **WebP**：次世代の高圧縮画像フォーマット（おすすめ）
  - **JPEG**：汎用的な写真フォーマット
  - **PNG**：透明度（アルファチャンネル）を維持する可逆フォーマット
- **リアルタイム画質調整**：
  - 10%〜100% のスライダー調整で、画質とファイルサイズのバランスを即座にシミュレーション
- **スマートリサイズ**：
  - 原寸維持
  - 比率縮小（75%, 50%, 25%）
  - 最大幅（px）指定リサイズ（アスペクト比は完全自動維持）
- **EXIF情報の自動削除**：
  - 撮影日時、位置情報（GPS座標）、カメラ機種情報などのメタデータを描画時に自動除去し、SNS投稿時などのプライバシー漏洩を防止

### 3. 直感的で快適なUI
- **複数画像の一括ドラッグ＆ドロップ対応**
- **リアルタイム削減率表示**（例：`-68% 削減！`）
- **一括ZIPダウンロード**：変換後の全画像をまとめたZIPファイルをワンクリックで生成・保存
- **個別ダウンロード**：1枚ごとの保存にも対応
- **ワンクリックサンプル生成**：手元に画像がなくても即座に機能を試せるテスト画像生成ボタン付き

## 🚀 使い方
1. [index.html](file:///c:/Users/Yuuki/OneDrive/Desktop/自作ツール/tools/image-tools/index.html) をブラウザで開きます。
2. 上部のドロップゾーンに画像をドラッグ＆ドロップ（またはファイルを選択）します。
3. 必要に応じて「フォーマット」「画質」「リサイズ」を設定します。
4. 「一括ダウンロード (ZIP)」または各カードの「保存」ボタンをクリックして完了です！
