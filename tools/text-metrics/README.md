# TextMetrics PRO - 洗練されたリアルタイム文字数カウント＆分析Webアプリ

モダンで美しいUIと高精度なテキスト分析機能を備えた、使いやすい文字数カウントWebアプリケーションです。

---

## 🌟 主な機能と特徴

### 1. リアルタイム文字数カウント＆詳細分析
- **総文字数（スペース含む）**：絵文字やサロゲートペアにも対応した正確な文字数
- **文字数（スペース除く）**：空白・改行・タブを除去した純粋な文字数
- **原稿用紙換算（400字詰）**：総枚数（天井値）に加え、「○枚と○文字（○.○枚分）」まで詳細表示
- **読了時間の目安**：
  - 黙読の目安（約600文字/分）
  - 音読の目安（約350文字/分）
- **行数カウント**：総行数 ＆ 空行を除いた実効行数
- **単語数・段落数・データ容量**：日英混在単語数、段落数、UTF-8バイト数
- **文字種類の内訳分析（ビジュアルバー＆割合表示）**：
  - ひらがな
  - カタカナ
  - 漢字
  - 英数字
  - 記号・空白・その他

### 2. 作業効率を高める便利機能
- **ワンクリックコピー**：テキスト全体を瞬時にクリップボードへコピー（トースト通知付き）
- **全消去ボタン**：ワンクリックで入力をクリア（誤操作防止アラート付き）
- **テキスト整形メニュー**：
  - ✨ **スマート整形（おすすめ）**：各行末尾のスペース削除、連続空白を1つに統合、過度な連続改行を2行に圧縮
  - ␣ **全てのスペースを除去**：全角・半角スペースを完全に削除
  - ⏎ **空行をすべて削除**：改行のみの行を削除してテキストを詰める
  - ✂️ **各行の前後の空白を削除**：各行のインデントや行末空白をトリム
  - 🔤 **英数記号を半角に統一**：全角の英数字・記号を半角に変換
- **目標文字数設定＆プログレスバー**：レポートやSNS、記事執筆などの目標文字数と進捗（残り文字数）を可視化
- **サンプル文章ボタン**：夏目漱石の『吾輩は猫である』のサンプルを読み込んで即座に機能を試せます
- **自動保存（localStorage）**：入力テキストや目標値はブラウザ内に自動保存されるため、タブを閉じても安全です

### 3. 洗練されたモダンデザイン
- **グラスモーフィズム ＆ アンビエントグロー**：深みのあるダークモードと、清潔感のあるライトモードをワンクリックで切り替え可能
- **カードスタイル**：重要な数値がひと目でわかる視認性に優れたレイアウト
- **レスポンシブ対応**：スマートフォン、タブレット、PCのどの画面サイズでも快適に利用可能

---

## 🚀 使い方
本アプリは外部サーバーやビルドツールを必要としない**スタンドアローン（Vanilla HTML/CSS/JS）**構成です。

1. フォルダ内の `index.html` をダブルクリック（またはお好みのブラウザで開く）してください。
2. すぐにアプリが起動し、テキスト入力や分析がご利用いただけます。
